# Frontend

Клиент на React. Порядок настройки API и PostgreSQL описан в [README проекта](../README.md).

```sh
npm ci
npm run dev
npm run build
```

Vite направляет запросы `/api` к локальному FastAPI на порту 8000. Сборка создаётся в `dist`. Для живого входа открой Mini App через Telegram.

Для локального показа с тестовыми сессиями ведущего и гостя можно задать `VITE_BROWSER_INVITE_BASE=http://localhost:18125/` при сборке. В лобби кнопка «Копировать» выдаст браузерный адрес гостя с кодом приглашения. Обычная сборка выдаёт ссылки Telegram.

## Проверка пользовательских сценариев

```sh
npx playwright install chromium
npm test
```

В наборе проверяются отказы при входе и приглашении. Для полного сценария запусти локальный API на отдельной тестовой PostgreSQL с `DREAMTEAM_INSECURE_LOCAL_COOKIE=1` и тестовым токеном. Укажи тот же тестовый токен в `DREAMTEAM_E2E_BOT_TOKEN` при запуске Playwright.

Сквозные сценарии проверяют пять карточек с силой 50, сохранение тактики, одно лобби у двух игроков, одинаковый итог Mirage после обновления и закрытие лобби гостем. На Android и iOS сценарий можно повторить через Telegram с двумя реальными тестовыми аккаунтами. При ручной проверке фиксируйте устройство, версию и фактический исход.
