## Что применили

| Тема | Изменение в Dreamteam | Как проверить |
|---|---|---|
| Компоненты, списки и ключи в React | [Экран команды](../../frontend/src/features/team/team.jsx) строит карточки по ответу API. Ключ карточки — сохранённый слот. Видны имя, роль и сила каждого игрока. | Открыть «Команда» после входа. Должны появиться пять карточек с силой 50. |
| Состояние UI, побочные эффекты и повторное открытие | [Оболочка приложения](../../frontend/src/App.jsx) выбирает экран, [лобби](../../frontend/src/features/play/lobby.jsx) показывает подготовку, а [компонент результата](../../frontend/src/features/play/result.jsx) показывает счёт и раунды из сохранённого результата. | Войти по приглашению в двух браузерных сессиях, подтвердить готовность и обновить обе страницы. |
| Сквозные проверки пользовательского пути | [Браузерные тесты](../../frontend/tests/acceptance.spec.js) проверяют пять карточек, одинаковый итог у обоих игроков и закрытие лобби гостем. Для проекта выбран Playwright. | Запустить тесты на десктопном и мобильном профилях Chromium по [инструкции](../../frontend/README.md). |
